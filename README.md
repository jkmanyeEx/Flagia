# Flagia — 과정 중심 정직한 글쓰기 증명 플랫폼

키스트로크 다이나믹스 분석 기반 학술 글쓰기 무결성 검증 시스템.

학생이 에디터에서 글을 쓰는 동안 키 입력 패턴을 실시간으로 수집·분석하여, 사람이 직접 작성했는지를 수학적으로 증명합니다.

---

## 기능 요약

### 교사

| 기능 | 설명 |
|------|------|
| **과제 생성** | 제목, 마감일, 제한 시간, 권장 글자 수, 초안 템플릿, 민감도 모드 설정 |
| **민감도 모드** | STRICT · STANDARD · RESEARCH · CREATIVE — 과제 유형에 따라 분석 가중치 자동 조절 |
| **제출 현황 조회** | 학생별 Flagia Score 게이지, 플래그 뱃지(🟢 안전 · 🟡 주의 · 🔴 위험), 상세 지표 테이블 |
| **Kill Switch** | 시험 중 전체 학생 작성을 원격으로 즉시 강제 종료 |

### 학생

| 기능 | 설명 |
|------|------|
| **과제 목록** | 배정된 과제 확인, 마감일·시간·글자 수 표시 |
| **마크다운 에디터** | 제목, 굵게, 기울임, 취소선, 인용, 리스트, 표, 인라인 코드, 코드 블록 도구 모음 |
| **실시간 미리보기** | 마크다운 → HTML 렌더링 미리보기 토글 |
| **자동 제출** | 타이머 만료 / Kill Switch / 탭 닫기 시 자동 제출 |
| **이어 쓰기** | 세션 중단 후 재접속하면 기존 작성 내용 복원 |

## 분석 엔진 (Flagia Score)

Flagia Score는 4가지 지표의 가중 합산으로 산출되는 0-100점 척도입니다.

### 지표

| 지표 | 의미 | 인간 범위 |
|------|------|-----------|
| **IKI Cv** | 키 입력 간격(Inter-Key Interval)의 변동 계수 σ/μ | 0.3 – 0.8 |
| **Revision Ratio** | 총 키 입력 수 ÷ 최종 글자 수 | 1.2 – 2.5 |
| **Paste Count** | 붙여넣기 횟수 (코드 블록 인용 제외) | 0 – 2 |
| **Blur Duration** | 에디터 이탈 누적 시간 (초) | < 30초 |

### 모드별 가중치

```
              Cv      Revision   Paste    Blur
  STRICT    35%       25%       25%      15%
  STANDARD  30%       25%       25%      20%
  RESEARCH  25%       20%       30%      25%
  CREATIVE  20%       30%       25%      25%
```

### 플래그 판정

| 모드 | 🟢 GREEN | 🟡 AMBER | 🔴 RED |
|------|----------|----------|--------|
| STRICT | ≥ 75 | 50 – 74 | < 50 |
| STANDARD | ≥ 70 | 40 – 69 | < 40 |
| RESEARCH | ≥ 60 | 35 – 59 | < 35 |
| CREATIVE | ≥ 55 | 30 – 54 | < 30 |

## 사용 가이드

### 1. 교사 — 과제 생성

1. 회원가입 시 역할 **"교사"** 선택
2. 로그인 후 대시보드에서 **"+ 새 과제"** 클릭
3. 과제 정보 입력:
   - **과제 제목**: 과제 이름
   - **마감일**: 제출 마감 일시
   - **제한 시간**: 분 단위 (예: 60분)
   - **권장 글자 수**: 초과 시 경고 배너 표시
   - **초안 가이드라인 템플릿**: 마크다운 형식으로 작성 가이드 제공 — 학생 에디터에 사전 삽입됨
   - **민감도 모드**: 과제 유형에 맞는 분석 기준 선택
4. **"과제 생성"** 클릭

### 2. 교사 — 제출물 분석

1. 대시보드에서 과제 카드 클릭
2. 제출 현황 테이블 확인:
   - **점수**: Flagia Score 원형 게이지 (0-100)
   - **플래그**: 🟢 안전 / 🟡 주의 / 🔴 위험
   - **IKI Cv**: 키 입력 변동성 (낮으면 자동화 의심)
   - **수정 비율**: 키 입력 대비 글자 수 비율 (낮으면 복붙 의심)
   - **붙여넣기**: 외부 텍스트 붙여넣기 횟수
   - **이탈 시간**: 에디터에서 벗어난 누적 시간

> 🟡 AMBER 이상 학생에 대해서는 개별 면담 등 추가 확인을 권장합니다.

### 3. 교사 — Kill Switch

시험 중 **부정행위 발견** 또는 **시험 종료 시**:

1. 과제 카드 우측 **"⚡ Kill"** 버튼 클릭
2. 확인 대화상자에서 "확인" 선택
3. 해당 과제의 **모든 활성 세션이 즉시 강제 종료**되고 현재 작성 내용이 자동 제출됨

### 4. 학생 — 글쓰기

1. 회원가입 시 역할 **"학생"** 선택
2. 로그인 후 **"내 과제"** 목록에서 과제 확인
3. **"시작하기"** 클릭 → 에디터 진입
4. 상단 도구 모음으로 마크다운 서식 적용:

   | 버튼 | 기능 | 마크다운 |
   |------|------|----------|
   | **H** | 제목 | `# 텍스트` |
   | **B** | 굵게 | `**텍스트**` |
   | *I* | 기울임 | `*텍스트*` |
   | ~~S~~ | 취소선 | `~~텍스트~~` |
   | 66 | 인용 | `> 텍스트` |
   | • | 순서 없는 목록 | `- 항목` |
   | 1. | 순서 있는 목록 | `1. 항목` |
   | ⊞ | 표 삽입 | 마크다운 테이블 |
   | </> | 인라인 코드 | `` `코드` `` |
   | CB | 코드 블록 | ` ```코드``` ` |
   | 👁 | 미리보기 | 렌더링 결과 토글 |

5. 우측 상단 상태 확인:
   - **글자 수**: `현재 / 제한` — 초과 시 노란색 경고 배너
   - **타이머**: `MM:SS` — 60초 이하일 때 빨간색 점멸
   - **연결 상태**: 🟢 연결됨 / 🔴 재연결 중
6. 완료 시 **"제출"** 클릭 → 확인 대화상자 → 🔒 잠금

### 5. 학생 — 자동 제출 트리거

다음 상황에서 현재 작성 내용이 **자동 저장·제출**됩니다:

| 트리거 | 설명 |
|--------|------|
| ⏰ 타이머 만료 | 제한 시간 초과 시 자동 제출 |
| ⚡ Kill Switch | 교사가 원격으로 종료 시 즉시 제출 |
| 🚪 탭 닫기 | 브라우저 탭/창을 닫을 때 `sendBeacon`으로 긴급 제출 |
| 🔄 재접속 | 세션 중단 후 재접속하면 이전 작성 내용 복원, 이어 쓰기 가능 |

## 보안 체계

| 계층 | 메커니즘 |
|------|----------|
| **전송** | Cloudflare 터널을 통한 HTTPS/TLS 1.3 강제 적용 |
| **인증** | JWT 토큰 기반 세션 관리, 24시간 만료 |
| **비밀번호** | bcrypt (salt rounds = 12) |
| **텔레메트리 무결성** | SHA-256 해시 체이닝 — 각 이벤트의 해시가 이전 해시와 연결되어 변조 탐지 |
| **IME 필터링** | 한국어 조합 입력 시 `compositionstart/end` 이벤트 분리 처리 |

## 데이터베이스 스키마

```
users              assignments          submissions          sessions
├─ id (UUID PK)    ├─ id (UUID PK)      ├─ id (UUID PK)      ├─ id (UUID PK)
├─ name            ├─ teacher_id FK     ├─ assignment_id FK   ├─ submission_id FK
├─ email (UNIQUE)  ├─ title             ├─ student_id FK      ├─ start_time
├─ password_hash   ├─ due_date          ├─ final_markdown     ├─ end_time
├─ role (ENUM)     ├─ time_limit        ├─ status (ENUM)      ├─ ip_address
└─ created_at      ├─ text_limit        ├─ flagia_score       ├─ user_agent
                   ├─ template_text     ├─ flag_status        └─ events_blob (JSON)
                   ├─ mode (ENUM)       ├─ coefficient_of_variation
                   └─ created_at        ├─ revision_ratio
                                        ├─ total_paste_count
                                        └─ total_blur_duration
```
